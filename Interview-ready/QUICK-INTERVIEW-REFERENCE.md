## 📝 Common Interview Questions - Quick Answers

**Q: Explain the Event Loop**
A: "JavaScript is single-threaded with one Call Stack. The Event Loop manages async operations by checking if the Call Stack is empty, then executing all Microtasks (Promises) before executing one Macrotask (setTimeout). This allows non-blocking async behavior."

**Q: What is a closure?**
A: "A closure is when a function remembers variables from its outer scope even after that outer function has returned. React hooks use closures internally. Common use: data privacy, React state, event handlers."

**Q: Difference between Promise and Async/Await?**
A: "Async/await is syntactic sugar over Promises. It makes async code look synchronous and is easier to read, especially for error handling with try/catch. Both return promises, but async/await is cleaner for sequential operations."

**Q: Why use useEffect?**
A: "useEffect handles side effects in React - API calls, subscriptions, DOM manipulation. It runs after render and can clean up with a return function. Dependencies array controls when it re-runs."

**Q: What is debouncing?**
A: "Debouncing delays function execution until after a pause in events. I use it for search inputs to wait until the user stops typing before making an API call, reducing API calls from hundreds to one."

**Q: Arrow function vs regular function?**
A: "Main difference is 'this' binding. Arrow functions have lexical 'this' from parent scope, regular functions have dynamic 'this'. Arrow functions can't be constructors and don't have 'arguments' object. I use arrow for callbacks and array methods, regular for object methods."

**Q: What's the difference between map and forEach?**
A: "map returns a new array with transformed values, forEach just iterates and returns undefined. Use map when you need transformed data (especially in React for rendering), forEach for side effects only."

**Q: Deep copy vs shallow copy?**
A: "Shallow copy only copies first level (spread, Object.assign), nested objects remain referenced. Deep copy copies all levels (JSON.parse(JSON.stringify()), Lodash, structuredClone). In React, I use shallow copy for simple state, deep copy for nested objects to avoid mutations."

**Q: How does Virtual DOM work?**
A: "React creates a lightweight JavaScript representation of the DOM. On state change, React creates new Virtual DOM, compares with previous one (diffing), calculates minimal changes needed, then batch updates real DOM. This is much faster than updating real DOM directly."

**Q: What is scope chain?**
A: "When JavaScript looks up a variable, it starts in current scope, then checks parent scope, continues up to global scope. If not found, throws ReferenceError. This is why inner functions can access outer variables (closures!)."
